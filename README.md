# Edoardo Amadio — Economics Portfolio

Projects in applied economics and public policy, written in Python. I study at LUISS Guido Carli in Rome.

Each project has its own folder and its own README with the data, the method, how to run the code and the main
results.

## Projects

### [Moving the Cliff: Raising Italy's Flat-Tax Threshold](flat_tax_threshold/)
Policy evaluation of raising the revenue limit of Italy's flat-tax regime for the self-employed from
EUR 85,000 to EUR 100,000, with VAT still due from EUR 85,000. Bunching estimation, difference-in-bunching,
panel difference-in-differences and a fiscal microsimulation on a calibrated synthetic panel.
*Tools: Python (pandas, statsmodels, scipy), LaTeX.*

### [Eurozone Macroeconomic Analysis, 2000–2023](eurozone_analysis/)
GDP growth, unemployment and inflation in Italy, Germany, France, Spain and Greece, with a focus on the
2008–2013 financial and sovereign debt crises. World Bank data.
*Tools: Python (pandas, matplotlib), Jupyter.*
