# Moving the Cliff: Raising Italy's Flat-Tax Threshold for the Self-Employed

Code for a policy paper written for *Advanced Public Economics* (LUISS Guido Carli, 2026).

The paper evaluates a stylised version of the reform discussed for Italy's 2027 Budget Law: the revenue limit
of the *regime forfettario* (15% flat tax for the self-employed) rises from EUR 85,000 to EUR 100,000, while the
VAT exemption stays at EUR 85,000 because of EU rules (Directive 2020/285). It asks three questions:

1. Does the bunching just below EUR 85,000 move to EUR 100,000?
2. Does the response differ between sellers to businesses (B2B), for whom VAT is nearly neutral, and sellers to
   consumers (B2C), for whom it is a real cost?
3. How much of the direct revenue cost is offset, or amplified, by behavioural responses?

**All post-reform data are synthetic.** The simulation is calibrated so that 2024 declared revenues match the
official count of flat-tax users by revenue band (Corte dei conti, 2026); everything from 2027 onwards is
generated by the model in `sim.py`. The numbers are illustrations of the research design, not estimates of the
real reform.

## What the code does

| File | Role |
|---|---|
| `sim.py` | The model: revenue paths (growth, permanent and transitory shocks, sector shocks), tax rules (IRPEF with regional and municipal add-ons, flat tax, VAT), and each taxpayer's choice of how much revenue to declare under the old or new thresholds |
| `calibrate.py` | Fits the starting revenue distribution to the Corte dei conti band counts (optional: the fitted values are already hard-coded in `build.py`) |
| `build.py` | Simulates the same population twice, with and without the reform, and saves the panels to `data/` |
| `analysis.py` | Bunching and difference-in-bunching, panel difference-in-differences, crossing shares, purchases-to-revenue test, fiscal decomposition, robustness checks; writes `output/results.txt` and preview charts |
| `make_latex.py` | Writes the three exhibits of the paper as LaTeX (pgfplots figure, booktabs tables) to `latex/` |
| `checks.py` | Validation: simulated vs official band counts, hand-checked tax arithmetic, bunching estimator vs simulated truth, share of non-responders, sensitivity of the fiscal result; writes `output/checks.txt` |

## How to run

```bash
pip install -r requirements.txt
python build.py        # about 30 seconds; creates data/panel_reform.parquet and data/panel_noreform.parquet
python analysis.py
python make_latex.py
python checks.py
```

Run the scripts from the repository folder. The full panels (about 100 MB each) are not stored in the repository
because `build.py` regenerates them exactly (fixed random seeds). `data/sample_panel_2000_people.csv` is a small
extract for a quick look at the data structure.

The LaTeX exhibits need `pgfplots` (with the `groupplots` library), `booktabs` and `threeparttable`.

## Main results (synthetic data)

- **Bunching:** in 2028 a new spike forms below EUR 100,000; the spike at EUR 85,000 disappears for B2B sellers
  (1.8x to 1.1x the smooth counterfactual) but not for B2C sellers (2.3x to 2.2x). Difference-in-bunching
  -0.58 (s.e. 0.14), placebo -0.21 (s.e. 0.15).
- **Panel DiD:** among sellers stuck at EUR 82-85k in 2023, B2B sellers' declared revenue grows 3.2% (2027) and
  2.8% (2028) more than B2C sellers', with sector-by-year fixed effects; no effect in a placebo group at EUR 45-50k.
- **Fiscal effect, 2028:** direct cost EUR 777m, risers +EUR 61m, fallers -EUR 439m; net cost about EUR 1.16bn.
